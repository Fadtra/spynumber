# SPYNUMBER

SPYNUMBER adalah tool Python berbasis Termux untuk melakukan pemeriksaan
metadata nomor telepon dan pencarian informasi publik menggunakan mesin
pencari.

## Features

- Normalisasi nomor telepon Indonesia
- Pemeriksaan validitas nomor
- Deteksi negara/region
- Informasi operator
- Informasi timezone
- Deteksi tipe nomor
- Google OSINT search
- Bing OSINT search
- Menampilkan URL pencarian
- Berjalan di Termux/Linux
